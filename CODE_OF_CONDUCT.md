# Code of conduct

Be straightforward and be kind. Argue about the work, not the person. Assume the other person is
trying to make the app better, and say so when they have.

Harassment, personal attacks and discrimination of any kind are not tolerated here, in issues, pull
requests or anywhere else the project is discussed. Maintainers will remove such content and may
block the account responsible.

If something happens that you do not want to raise in public, contact the maintainers through the
repository's Security tab (private vulnerability reporting reaches the same people).
